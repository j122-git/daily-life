# Daily Life v0.2.0 — To-do module

## Included
- Replaced prompt-based task creation/editing with a proper form.
- Added a date picker and long-form due-date display.
- Added a category dropdown: Home, Shopping, Errands, Personal, Family.
- Made All / Today / Upcoming / Done filters functional.
- Completed tasks now show a solid green dot with no tick, plus strikethrough task text.
- Added edit and delete actions through the same task form.
- Kept the existing Worker API and authentication flow unchanged.
